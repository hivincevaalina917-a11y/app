Что здесь приблизительно / допущения
Ширина каждого модуля — только реальные точки из вашего прайса (без интерполяции между ними).

Надбавка за высоту корпуса считается отдельно на подытог группы ВЕРХ (по таблице «средний ряд») — как в вашем Excel. Для антресоли 300/600 высота уже заложена в цену конкретного модуля (выбор высоты 320/400/420 перед шириной).

Площадь фасадов = суммарная ширина модулей группы (м) × высота этой группы (м); для НИЗ высота фиксирована 0.72м, для пенала — 2.3 или 2.5м по бóльшей выбранной высоте пенала.

Петли считаются по таблице «высота × ширина двери» (sdelaimebel.ru) с интерполяцией между значениями сетки — применяется к НИЗ + ВЕРХ + антресоли + пенал (фасады-заглушки под технику — без петель).

Газлифты, пуш-системы, тандем-боксы, ручки, подсветка, стекло — сюда пока не включены (design-специфичные позиции, добавим по вашему запросу).

Себестоимость = цена клиенту ÷ 1.9; внутренний расчёт = себестоимость × 1.75 + реальные 10% на монтаж + допы — так же, как раньше.
